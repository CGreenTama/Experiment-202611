────────────────────────────────────────
0. 適用前提
────────────────────────────────────────

0-1. 対象単位
  1件の観光対象(施設・場所)を1事例とする。入力は施設名・営業時間・
  説明文などのメタデータとする。

0-2. 多ラベル前提
  本規則群は複数タイプの併記を許容する前提で記述する。単一ラベル運用に
  切り替える場合は、第3章の優先順位規則を用いて1タイプに縮約する。

0-3. 「観光的に魅力があるもの」ゲート
  原ラベル体系の但し書きは、対象リストが既に観光対象に絞られている前提で
  常に真として扱う。魅力度そのものの判定は本規則の範囲外とする。

0-4. 主題性の原則
  すべての規則に共通して、当該要素が記述の「主対象」であることを要求する。
  主対象とは、その場所を訪れる理由として説明文に提示されている要素を指す。
  付随的・背景的な言及は主題性を満たさない。

0-5. 固有名詞の不使用
  本規則群は固有名詞を含まない。改訂により新規則を追加する際も、特定の
  施設名・地名に依存した規則を導入してはならない。


────────────────────────────────────────
1. 自然資源(10タイプ)
────────────────────────────────────────

──────────
1-1. 山岳 [NAT_MOUNTAIN]
──────────
IF     説明文が、山体そのもの(山頂・山腹・山麓のいずれか)を訪問・鑑賞の
       対象として記述しており、標高差のある地形の踏破または遠望が
       主題である場合
THEN   NAT_MOUNTAIN を付与する。
EXCEPT 名称に山を示す語を含むが実体が市街地・住宅地・平地の公園である場合、
       山体が眺望の背景として言及されるにとどまる場合、または
       丘陵の緩斜面が公園として整備され緑地としての利用が主題である場合は、
       付与しない。
[JTB引用] JTB:地形図記載の山岳名称。山頂・山腹・山麓を含む広い範囲。山岳のまとまりとして認識される場合はその名称も可。

──────────
1-2. 高原・湿原・原野 [NAT_PLATEAU]
──────────
IF     説明文が、樹林に覆われない広がりのある自然地形(高原・湿原・草原・
       原野)を主対象として記述しており、その開けた景観または植生環境が
       訪問理由として提示されている場合
THEN   NAT_PLATEAU を付与する。
EXCEPT 人為的に造成・管理された芝地や広場である場合、または広がりへの
       言及が特定の植物種の鑑賞に従属している場合は、付与しない。
[JTB引用] JTB:地形図記載の高原・原野、沼沢以外の湿原。名称の有無に関わらず高原状・平原状の地形が対象。

──────────
1-3. 湖沼 [NAT_LAKE]
──────────
IF     説明文が、閉じた水面をもつ止水域(湖・池・沼)を主対象として記述して
       おり、水面の景観・水辺の周遊・水上活動のいずれかが訪問理由として
       提示されている場合
THEN   NAT_LAKE を付与する。
EXCEPT 水面が流水として記述される場合、噴水その他の小規模な人工水景に
       とどまる場合、名称に水域を示す語を含むが実際の水辺への言及を欠く
       場合、または庭園の構成要素として言及されるにとどまり水面自体が
       主対象でない場合は、付与しない。
[JTB引用] JTB:地形図記載の単独湖沼。自然地形を活かして造成されたダム湖も含む。

──────────
1-4. 河川・峡谷 [NAT_RIVER]
──────────
IF     説明文が、流水域(河川・渓流・渓谷・運河)を主対象として記述しており、
       流路沿いの景観・水辺の散策・水流そのものが訪問理由として提示されて
       いる場合
THEN   NAT_RIVER を付与する。
EXCEPT 流路にかかる構造物を通過した旨の記述にとどまり水域への具体的言及を
       欠く場合、または河口部・港湾部で海域との区別が判別しがたい場合は、
       付与しない(後者は 3-1 の優先順位規則に従う)。
[JTB引用] JTB:河川風景(河川+周辺)、および峡・峡谷・谷と呼ばれるもの。同一河川でも上流/中下流で魅力が異なれば別資源として扱う。

──────────
1-5. 滝 [NAT_WATERFALL]
──────────
IF     説明文が、落差をもつ流水の落下地点を主対象として記述しており、
       その景観または周辺の遊歩が訪問理由として提示されている場合
THEN   NAT_WATERFALL を付与する。
EXCEPT 人工的に造成された落水施設である場合、または上流・下流の流路が
       主題であって落下地点が経路上の一要素にとどまる場合は、付与しない。
[JTB引用] JTB:地形図記載の滝・諸瀑。複数の滝が同一名称でまとまりとして呼ばれる場合はその名称も可。

──────────
1-6. 海岸・岬 [NAT_COAST]
──────────
IF     説明文が、海域と陸域の接する地形(砂浜・断崖・岬・海岸線)または
       海域そのものを主対象として記述しており、海景の鑑賞・海辺の散策・
       海に由来する体験が訪問理由として提示されている場合
THEN   NAT_COAST を付与する。
EXCEPT 名称に海域を示す語を含むが説明文の主題が海に及ばない場合、
       海への言及が否定的文脈にとどまる場合、または屋内展示のみが
       主題である場合は、付与しない。
[JTB引用] JTB:砂浜・砂丘・砂州・岩礁・断崖等の海岸風景(背後地・松原を含む)、容易に見られる海中景観。

──────────
1-7. 岩石・洞窟 [NAT_ROCK]
──────────
IF     説明文が、特異な形状の岩体または地下空洞(奇岩・洞窟・鍾乳洞)を
       主対象として記述しており、その形状・規模・内部空間が訪問理由として
       提示されている場合
THEN   NAT_ROCK を付与する。
EXCEPT 石造構造物・石垣・人工的な坑道である場合、または岩体が信仰対象と
       して扱われ宗教施設の構成要素として記述されている場合は、付与しない。
[JTB引用] JTB:岩柱・洞窟・洞穴・岩門・鍾乳洞・溶岩流・断崖・岩礁・海蝕崖等の地質・地形上の興味対象。

──────────
1-8. 動物 [NAT_ANIMAL]
──────────
IF     説明文が、野生状態にある動物の生息地または観察地点を主対象として
       記述しており、自然状態での観察が訪問理由として提示されている場合
THEN   NAT_ANIMAL を付与する。
EXCEPT 動物が飼育下に置かれている場合、生息地が定まらない場合、観察が
       偶然性に左右される旨の記述である場合[v1.2、原典定義で明示的に
       確認]、または動物への言及が季節の景物としての付随的描写にとどまる
       場合は、付与しない。
[JTB引用] JTB:日本特有/日本の自然環境に特有/日本著名の動物とその生息地。生息地不定・偶然性に左右されるもの・動物園等での飼育は対象外。

──────────
1-9. 植物 [NAT_PLANT]
──────────
IF     説明文が、特定の植物(花木・巨木・花畑・季節の植生)を主対象として
       記述しており、その植物の鑑賞が訪問理由として提示されている場合
THEN   NAT_PLANT を付与する。当該地が整備された緑地である場合は
       CUL_GARDEN を併記する。
EXCEPT 植物名が施設名の一部としてのみ現れる場合、街路樹その他の付随的な
       緑への軽微な言及にとどまる場合、または植物が庭園の意匠を構成する
       一要素として述べられるにとどまり個々の植物が鑑賞対象として
       提示されていない場合は、付与しない。
[JTB引用] JTB:名木・巨樹・老樹・並木・森林・植物帯・植物群落・自生地等。複数ある場合は評価の高い方を代表させる。寺社・城・園地内の植物は原則その種別に含め、それ以上に植物が特徴的な場合のみ本タイプ。

──────────
1-10. 自然現象 [NAT_PHENOMENON]
──────────
IF     説明文が、特定の気象・天文・季節現象(火山現象、潮流現象、樹氷・
       霧氷・流氷、不知火・蜃気楼など出現箇所や時期が限定される現象)を
       主対象として記述しており、その現象の観測が訪問理由として提示されて
       いる場合
THEN   NAT_PHENOMENON を付与する。
EXCEPT 夕日・朝日・星空など日本全国どこでも共通して見られる現象である
       場合[v1.2]、現象への言及が眺望の質を修飾する表現にとどまる場合、
       夜景など人工光の景観が主題である場合、または現象が生起する地形の
       側が主対象である場合は、付与しない。
[JTB引用] JTB:火山現象・潮流現象・気象現象(樹氷・霧氷・流氷等)で学術的価値の高いもの。夕日・星空等全国共通のものは除く。不知火・蜃気楼等、出現箇所・時期が限定されるものが対象。


────────────────────────────────────────
2. 人文資源(14タイプ)
────────────────────────────────────────

──────────
2-1. 史跡 [CUL_HISTSITE]
──────────
IF     説明文が、歴史的な出来事・営為の痕跡が残る場所(遺跡・跡地・旧地)を
       主対象として記述しており、現存する建築物ではなく場所そのものの
       歴史的意義が訪問理由として提示されている場合
THEN   CUL_HISTSITE を付与する。
EXCEPT 現存建築物が主対象である場合(原ラベル体系の「建物が主でないもの」
       という規定による)、または歴史的経緯への言及が施設の沿革説明に
       とどまり訪問理由として提示されていない場合は、付与しない。
[JTB引用] JTB:生活・政治・祭・信仰・教育学芸・社会事業・産業土木・外国人等に関する遺跡(城跡を除く)。城・現役の社寺・復元建造物はそれぞれ独立した種別として扱う。

──────────
2-2. 神社・寺院・教会 [CUL_RELIGIOUS]
──────────
IF     説明文が、宗教的機能をもつ施設を主対象として記述しており、
       参拝・礼拝・信仰に関わる場としての性格が訪問理由として提示されて
       いる場合
THEN   CUL_RELIGIOUS を付与する。
EXCEPT 宗教施設が地名・区域名の一部としてのみ現れる場合、または建築物が
       宗教的機能から切り離され美術的・建築史的対象としてのみ記述される
       場合は、付与しない(後者は 3-4 に従う)。
[JTB引用] JTB:由緒ある建築的に優れた社寺、文化財を所蔵・付帯する社寺、境内(庭園含む)が優れた社寺等。塔頭・庭園・植物を含めて評価するが、植物が社寺以上に特徴的な場合は1-9。

──────────
2-3. 城跡・城郭・宮殿 [CUL_CASTLE]
──────────
IF     説明文が、防御的構造をもつ建築物または君主の居館を主対象として
       記述しており、現存または復元された建築物の観覧が訪問理由として
       提示されている場合
THEN   CUL_CASTLE を付与する。
EXCEPT 建築物が失われ地割・石垣・土塁などの痕跡のみが残る場合は、
       CUL_HISTSITE を付与し本タイプは付与しない。
[JTB引用] JTB:古代から近世の軍事・行政目的で建造された城跡・城郭(庭園を含む)・宮殿。城内の植物は植物がそれ以上に特徴的でない限り本タイプに含める。

──────────
2-4. 集落・街 [CUL_TOWNSCAPE]
──────────
IF     説明文が、農山漁村・歴史的街並み・伝統的建造物群保存地区・常設の
       商店街・繁華街など、複数の建築物からなる面的な市街景観を主対象
       として記述している場合[v1.2、回遊要件を削除し常設の商店街・
       伝建地区を明示]
THEN   CUL_TOWNSCAPE を付与する。
EXCEPT 区域内の単一の建築物が主対象である場合、市場が主対象である場合
       (2-5 に従う)、または住民の生業と結びついた景観が主題である場合
       (3-6 に従う)は、付与しない。
[JTB引用] JTB:農山漁村・歴史的街並み・繁華街・商店街等による特徴的な集落・街区。伝建地区・常設の商店街は本タイプで評価する(市場は2-5)。

──────────
2-5. 郷土景観 [CUL_LOCALSCAPE]
──────────
IF     説明文が、当該地の生業・生活様式によって形成された景観(農地の
       造形・漁村・産業景観・市場・街道など)を主対象として記述しており、
       生活との結びつきが景観の説明に不可欠な要素として提示されている場合
       [v1.2、市場・街道を明示]
THEN   CUL_LOCALSCAPE を付与する。植物が産業として栽培されている場合も
       本タイプとして扱う[v1.2]。
EXCEPT 生業への言及を欠き建築物の集積としてのみ記述される場合(常設の
       商店街・繁華街は 2-4 に従う)、または生業が現在は行われておらず
       遺構としてのみ残る場合(CUL_HISTSITE を優先)は、付与しない。
[JTB引用] JTB:生業・風習・産業・人の織りなす風景(動作を含む)による特徴的な景観。文化的景観・市場・街道・産業としての植物栽培は本タイプで評価する(常設の商店街は2-4)。

──────────
2-6. 庭園・公園 [CUL_GARDEN]
──────────
IF     説明文が、意図的に作庭・造成された緑地空間(庭園・公園・緑地・
       臨海公園)を主対象として記述しており、その空間内での滞在・散策・
       景観鑑賞が訪問理由として提示されている場合
THEN   CUL_GARDEN を付与する。
EXCEPT 当該地を訪れた旨の記述にとどまり空間の内容への言及を欠く場合、
       施設名に緑を示す語を含むのみで実体が緑地でない場合、自然地形を
       主体とする自然公園である場合[v1.2]、体験要素の強い公園である
       場合(2-11 に従う)[v1.2]、または敷地内の建築物が主対象である
       場合(3-3 に従う)は、付与しない。
[JTB引用] JTB:鑑賞・散策のために作庭・造成された庭園・公園。社寺・城郭に含まれるもの、自然公園は対象外。体験要素の強い公園は2-11。

──────────
2-7. 建造物 [CUL_BUILDING]
──────────
IF     説明文が、単体の構築物(橋梁・塔・近代建築・記念構造物など)を
       主対象として記述しており、その構造・意匠・規模が訪問理由として
       提示されている場合
THEN   CUL_BUILDING を付与する。
EXCEPT 構築物が展示・宗教・興行など他の機能を主として運営されている場合
       (当該機能に対応するタイプを優先)、構築物が眺望を得るための
       経由地としてのみ言及される場合、または複数建築物の集積が
       面的に主題である場合(3-5 に従う)は、付与しない。
[JTB引用] JTB:建物・橋・塔等の建築物・構築物(社寺・城郭に含まれるものを除く)。複数の建造物が集積するものは2-4または2-5。現存/復元された昔の建物は本タイプ。

──────────
2-8. 年中行事 [CUL_EVENT]
──────────
IF     説明文が、特定の時期に開催される催事(祭礼・季節行事・催し)を
       主対象として記述しており、その開催期間中の来訪が訪問理由として
       提示されている場合
THEN   CUL_EVENT を付与する。
EXCEPT 催事への言及が開催実績の列挙にとどまり当該対象の主題を構成しない
       場合、または通年で提供される演目・興行である場合(3-8 に従う)は、
       付与しない。
[JTB引用] JTB:社寺・市町村・各種団体が開催日を決めて行う年中行事。宗教性のある祭り、地域固有で根付いたイベントの一部(盆踊り系・花火系)を含む。

──────────
2-9. 動植物園・水族館 [CUL_ZOO]
──────────
IF     説明文が、動物または植物を飼育・栽培して公開する施設を主対象として
       記述しており、その展示の観覧が訪問理由として提示されている場合
THEN   CUL_ZOO を付与する。
EXCEPT 生物が自然状態で観察される場合(NAT_ANIMAL または NAT_PLANT を
       付与)、または生物標本が学術資料として展示される施設である場合
       (CUL_MUSEUM を優先)は、付与しない。
[JTB引用] JTB:国内外の動植物を収集・飼育・展示する施設。入域が管理された植物は、それがどれほど特徴的でも1-9ではなく本タイプで評価する。

──────────
2-10. 博物館・美術館 [CUL_MUSEUM]
──────────
IF     説明文が、資料・作品を収集し展示する施設(博物館・美術館・資料館・
       記念館)を主対象として記述しており、展示の観覧が訪問理由として
       提示されている場合
THEN   CUL_MUSEUM を付与する。
EXCEPT 展示より参加型の遊戯・体験が施設の中心である場合(3-9 に従う)、
       または収蔵建築物自体が主対象である場合は、付与しない。
[JTB引用] JTB:国内外の歴史的・科学的資料や美術作品を収集・保存・展示する施設、および歴史的事象の記録・保存のために作られた園地。博物館、野外博物館、美術館、文学館、科学館、記念館等を含む。

──────────
2-11. テーマ公園・テーマ施設 [CUL_THEMEPARK]
──────────
IF     説明文が、特定の主題のもとに構成された遊戯・体験施設を主対象として
       記述しており、参加型の娯楽体験が訪問理由として提示されている場合
THEN   CUL_THEMEPARK を付与する。
EXCEPT 施設の中心が資料の展示にある場合(CUL_MUSEUM を優先)、
       飲食の提供が中心である場合(3-7 に従う)、または屋外の緑地空間と
       しての性格が主題である場合は、付与しない。
[JTB引用] JTB:特徴的な概念(テーマ)を表現し、それを体験するために作られた園地・施設。

──────────
2-12. 温泉 [CUL_ONSEN]
──────────
IF     説明文が、温泉を利用する施設または温泉地を主対象として記述しており、
       入浴または湯を用いた体験が訪問理由として提示されている場合
THEN   CUL_ONSEN を付与する。
EXCEPT 加温された一般の浴場・入浴施設である場合、または宿泊施設の
       付帯設備として言及されるにとどまる場合は、付与しない。
[JTB引用] JTB:温泉浴を体験できる施設、またはその場での温浴行為。温泉旅館等の温浴場に付帯する宿泊施設そのものは対象外。

──────────
2-13. 食 [CUL_FOOD]
──────────
IF     説明文が、飲食の提供またはその地の食文化を主対象として記述しており、
       飲食そのものが訪問理由として提示されている場合
THEN   CUL_FOOD を付与する。
EXCEPT 飲食施設が他の主対象に付帯する設備として言及されるにとどまる場合、
       または特定の料理を供する店舗が面的に集積した区域全体が主題である
       場合(3-7 に従う)は、付与しない。
[JTB引用] JTB:日本または地域の自然・歴史・文化を表す特徴的な食事・食文化・食事環境。料理が対象で食材は対象外。特定の店の料理は対象外だが、その土地の名物として認識される老舗は対象。主食・主菜が主対象で、土産は原則対象外だが菓子類は対象。

──────────
2-14. 芸能・スポーツ [CUL_PERFORM]
──────────
IF     説明文が、上演または競技の観覧を目的とする施設(劇場・演芸場・
       競技場など)を主対象として記述しており、公演・試合の鑑賞が訪問理由
       として提示されている場合
THEN   CUL_PERFORM を付与する。
EXCEPT 施設が建築的対象としてのみ記述される場合(CUL_BUILDING を優先)、
       または特定時期に限定された催事が主題である場合(3-8 に従う)は、
       付与しない。
[JTB引用] JTB:日本または地域の風土・歴史・文化を表す芸能・スポーツ。民謡大会系・音楽祭系を含む。土地との結びつきが弱いもの、歴史が浅いもの(10年未満、音楽祭系は30年未満)は対象外。


────────────────────────────────────────
3. 優先順位規則(競合ペア)
────────────────────────────────────────

以下は、複数タイプの条件が同時に成立しうる場合の解決規則である。
単一ラベル運用では縮約規則として、多ラベル運用では併記可否の判断規則
として用いる。

3-1. NAT_COAST / NAT_RIVER の競合
  IF     水域が海域と流水域の接続部(河口・港湾)に位置し区別が
         判別しがたい場合
  THEN   NAT_COAST を優先する。
  EXCEPT 説明文が明示的に流路の上流方向を主題としている場合は
         NAT_RIVER を優先する。

3-2. NAT_LAKE / NAT_RIVER の競合
  IF     水域が人工的に開削され流水と止水の性格を併せ持つ場合
  THEN   説明文における水面の記述が静止的であれば NAT_LAKE を、
         流路としての連続性を強調していれば NAT_RIVER を付与する。
  EXCEPT 判断材料が説明文に存在しない場合は、いずれも付与しない。

3-3. CUL_GARDEN / CUL_HISTSITE / CUL_BUILDING の競合
  IF     整備された緑地空間の内部に歴史的建築物または歴史的痕跡が
         所在する場合
  THEN   多ラベル運用では両者を併記する。単一ラベル運用では、説明文が
         建築物の観覧を訪問理由として提示していれば CUL_BUILDING または
         CUL_HISTSITE を、空間内での滞在・散策を提示していれば
         CUL_GARDEN を選択する。
  EXCEPT 建築物への言及が沿革の説明にとどまる場合は CUL_GARDEN のみと
         する。

3-4. CUL_RELIGIOUS / CUL_BUILDING の競合
  IF     宗教施設の建築物が意匠・構造の対象として記述されている場合
  THEN   CUL_RELIGIOUS を優先する。
  EXCEPT 当該建築物が宗教的機能を停止し、専ら建築史的・美術的対象として
         公開されている場合は CUL_BUILDING を付与する。

3-5. CUL_BUILDING / CUL_TOWNSCAPE の競合
  IF     複数の建築物が同一区域に所在する場合
  THEN   説明文が個別の建築物を特定して記述していれば CUL_BUILDING を、
         区域全体の景観的まとまりを記述していれば CUL_TOWNSCAPE を
         付与する。
  EXCEPT 両者が並立して記述されている場合は、多ラベル運用に限り併記する。

3-6. CUL_TOWNSCAPE / CUL_LOCALSCAPE の競合
  IF     市街景観が特定の生業と結びついて記述されている場合
  THEN   CUL_LOCALSCAPE を優先する。
  EXCEPT 生業への言及が歴史的沿革にとどまり現在の景観を規定していない
         場合は CUL_TOWNSCAPE を付与する。

3-7. CUL_FOOD / CUL_TOWNSCAPE / CUL_THEMEPARK の競合
  IF     飲食施設が面的に集積した区域が主対象である場合
  THEN   CUL_FOOD を付与し、区域の街並みが独立して記述されている場合に
         限り CUL_TOWNSCAPE を併記する。
  EXCEPT 集積が単一事業者により主題的に構成された施設内にある場合は
         CUL_THEMEPARK を優先する。

3-8. CUL_EVENT / CUL_PERFORM の競合
  IF     上演・競技が特定の時期に限定して開催される場合
  THEN   CUL_EVENT を付与する。
  EXCEPT 通年で継続的に提供される演目であり、施設の恒常的機能として
         記述されている場合は CUL_PERFORM を付与する。

3-9. CUL_MUSEUM / CUL_THEMEPARK の競合
  IF     施設が展示と参加型体験の双方を提供する場合
  THEN   説明文が資料・作品の内容に言及していれば CUL_MUSEUM を、
         体験行為そのものを訪問理由として提示していれば CUL_THEMEPARK を
         付与する。
  EXCEPT 双方が対等に記述されている場合は、多ラベル運用に限り併記する。

3-10. NAT_PLANT / CUL_GARDEN の競合
  IF     整備された緑地空間において特定の植物が鑑賞対象として記述されて
         いる場合
  THEN   両者を併記する(1-9 の THEN 節による)。
  EXCEPT 植物が意匠の構成要素として述べられるにとどまる場合は
         CUL_GARDEN のみとする。

3-11. NAT_MOUNTAIN / 眺望に関する記述の扱い
  IF     高所からの遠望が主題であり、当該地点自体の地形が
         記述されていない場合
  THEN   地点の性格に対応するタイプ(CUL_BUILDING、CUL_GARDEN 等)を
         付与する。
  EXCEPT 遠望の対象が特定の自然現象である場合は NAT_PHENOMENON を
         併記する。


────────────────────────────────────────
4. 全タイプに共通する非付与条件
────────────────────────────────────────

4-1. 名称のみの一致
  対象の名称にタイプを示す語が含まれるのみで、説明文が当該タイプの
  内容に及ばない場合は、いかなるタイプも当該根拠では付与しない。

4-2. 否定的言及
  ある要素が「存在しない」「見られない」旨の記述である場合、
  当該要素を根拠とするタイプは付与しない。

4-3. 付随的言及
  要素への言及が、主対象の説明を修飾する副次的記述にとどまる場合は
  付与しない。

4-4. 営業時間等のメタデータのみを根拠とする付与
  営業時間・所在地・料金などの事務的情報のみを根拠として
  タイプを推定してはならない。

4-5. 説明文に根拠を欠く推論
  対象の一般的知識に基づき、説明文に記載のない属性を補ってタイプを
  付与してはならない。

4-6. 周辺情報に終始する説明文の扱い [v1.1 で追加]
  IF     説明文が、季節・混雑状況・価格・交通手段・滞在時間・来訪の
         きっかけなど、観光資源としての特徴以外の周辺情報に終始しており、
         いずれのタイプについても具体的な記述を欠く場合
  THEN   対象の名称・一般的な知名度・類似の対象で典型的に語られる内容を
         根拠にタイプを補ってはならない。該当するタイプを裏付ける記述が
         説明文中に存在しない場合は、いかなるタイプも付与せず、
         その他を返す。
  EXCEPT 説明文が固有名詞(建物名・展示名・料理名など)を明示して
         言及している場合は、その固有名詞が示す対象を根拠としてタイプを
         付与してよい。また、説明文が複数の施設・区画にまたがる場合
         (例:ある区画について具体的に記述し、別の区画には触れない)、
         具体的な記述のある区画についてのみタイプを判断し、
         触れられていない区画については本規則を適用する。

  NOTE   本規則は 4-5 を一般化し、「周辺情報のみで具体的な特徴描写を
         欠く」という検出可能な条件を明示したものである。4-5 は
         引き続き、具体的な特徴描写はあるが対象外の一般知識で
         タイプを補う場合に適用する。


────────────────────────────────────────
5. 出力形式
────────────────────────────────────────

5-1. 出力は次の構造をとる。

     {"types": ["CUL_GARDEN", "NAT_PLANT"]}

5-2. タイプは第1章・第2章に定義した識別子のみを用いる。
     日本語表記・表記揺れを出力してはならない。

5-3. 該当するタイプが存在しない場合は空配列を返す。

     {"types": []}

     [v1.1] 「その他」をタイプの一つとして出力する運用を取る場合は、
     本規則とは別にその定義と出力形式を明記し、空配列との使い分けを
     一貫させること。本版(v1.1)は 4-6 の「その他」を、この空配列と
     同じ意味(該当タイプなし)の記法として扱う。両者が実行環境の
     出力スキーマ上で区別される場合は、4-6 の「その他」を
     当該スキーマの明示的な無該当カテゴリに読み替えること。

5-4. 出力に説明・理由付けを含めない。

────────────────────────────────────────
7. 事例集 [v1.1 で追加、6-2 対応]
────────────────────────────────────────

各タイプにつき正例2件・境界例(非付与)1件を示す。すべて架空の記述であり、
実在の施設を指すものではない(0-5)。出典の別は末尾に [データ] [定義のみ]
で示す。[データ]は横浜観光レビューDB等で見られた実際の不一致パターンを
抽象化したもの、[定義のみ]は対象タイプが評価用データに出現しなかった
ため、JTB公式ページ(https://tabi.jtb.or.jp/about/type/、観光資源タイプ
の原典定義)からのみ作成したもので、実例による検証を経ていない。
[v1.2] 全24タイプの定義文を同公式ページで直接確認した。[データ]区分の
9タイプも、このページの但し書き(「なお、〜」)と齟齬がないことを確認
済みである。

1-1. 山岳 [NAT_MOUNTAIN] [定義のみ・未検証]
  正例1    山頂からの眺めが素晴らしく、登山道もよく整備されていました。山腹
           の紅葉も見事でした。
  正例2    麓から山全体を見上げると、その稜線の美しさに圧倒されます。
  境界例    「〇〇山公園」という名前でしたが、実際はなだらかな丘を整備した市
           街地の緑地で、山登りをする場所ではありませんでした。→ 付与しな
           い(1-1 EXCEPT)。

1-2. 高原・湿原・原野 [NAT_PLATEAU] [定義のみ・未検証]
  正例1    見渡す限りの草原が広がり、風を感じながら歩くだけで気持ちが良かっ
           たです。
  正例2    湿原に特有の植生が広がっていて、木道からの眺めが開放的でした。
  境界例    「芝生広場」と呼ばれていましたが、実際は整地された人工の芝生で、
           自然の草原ではありませんでした。→ 付与しない(1-2 EXCEPT)。

1-3. 湖沼 [NAT_LAKE] [データ]
  正例1    静かな湖面に周囲の木々が映り込み、ボートで周遊できるのも良かった
           です。
  正例2    池の畔を一周する散策路があり、水面の景色を楽しみながら歩けました。
  境界例    公園の中に小さな池がありましたが、公園全体の設備の一つとして触れ
           られているだけで、池そのものが目的ではありませんでした。→ 付与
           しない(1-3 EXCEPT、庭園の構成要素)。

1-4. 河川・峡谷 [NAT_RIVER] [定義のみ・未検証]
  正例1    渓谷沿いの遊歩道を歩き、川のせせらぎを聞きながら散策しました。
  正例2    両岸の切り立った岩壁が続く峡谷の景観に圧倒されました。
  境界例    川にかかる橋を渡った、とだけ書かれていて、川そのものの景色への言
           及はありませんでした。→ 付与しない(1-4 EXCEPT)。

1-5. 滝 [NAT_WATERFALL] [定義のみ・未検証]
  正例1    落差のある滝の迫力がすごく、マイナスイオンを感じました。
  正例2    滝つぼまで近づける遊歩道があり、間近で水しぶきを浴びられました。
  境界例    人工の噴水が「滝」と呼ばれていましたが、自然の滝ではありませんで
           した。→ 付与しない(1-5 EXCEPT)。

1-6. 海岸・岬 [NAT_COAST] [定義のみ・未検証]
  正例1    砂浜が広がっていて、波の音を聞きながらのんびり過ごせました。
  正例2    断崖から見える海岸線の景色が印象的でした。
  境界例    公園が海に面していると書かれているだけで、砂浜や岩礁など海岸地形
           そのものへの言及はありませんでした。→ 付与しない(1-6 EXCEPT)。

1-7. 岩石・洞窟 [NAT_ROCK] [定義のみ・未検証]
  正例1    鍾乳洞の中は神秘的で、形の面白い鍾乳石がたくさんありました。
  正例2    奇岩が並ぶ海岸線を歩き、自然が作った造形に驚きました。
  境界例    石垣が立派だと書かれていましたが、これは人工の石造構造物で、自然
           の岩体ではありませんでした。→ 付与しない(1-7 EXCEPT)。

1-8. 動物 [NAT_ANIMAL] [定義のみ・未検証]
  正例1    野鳥の群れが飛来する様子を間近で観察できました。
  正例2    この地域に特有の野生動物が生息していると聞き、運良く姿を見ること
           ができました。
  境界例    動物園で飼育されている動物を見た、という記述でした。施設としての
           観覧なら2-9を検討します。→ 1-8は付与せず2-9を検討。

1-9. 植物 [NAT_PLANT] [データ]
  正例1    満開の桜並木が見事で、写真を撮る人で賑わっていました。
  正例2    樹齢数百年とされる巨木があり、その存在感に圧倒されました。
  境界例    広い公園の中に植物が植えられている、という記述にとどまり、個々の
           植物が鑑賞の対象として特に取り上げられていませんでした。→ 付与
           しない(1-9 EXCEPT)。

1-10. 自然現象 [NAT_PHENOMENON] [定義のみ・未検証]
  正例1    運良く流氷が接岸しているのを見ることができ、貴重な体験でした。
  正例2    雲海が眼下に広がる光景は、その時期・その場所でしか見られないもの
           でした。
  境界例    「夕日がきれいだった」とだけ書かれていました。夕日はどこでも見ら
           れる現象なので対象外です。→ 付与しない(1-10 EXCEPT)。

2-1. 史跡 [CUL_HISTSITE] [定義のみ・未検証]
  正例1    かつてここに集落があった痕跡が残されていて、当時の暮らしに思いを
           馳せました。
  正例2    古戦場として知られる場所で、現地の案内板で歴史的背景を知ることが
           できました。
  境界例    歴史ある場所に、現在は復元された建物が建っていて、その建物の見学
           が中心でした。→ 建物が主対象なら2-7や2-3を検討(2-1
           EXCEPT)。

2-2. 神社・寺院・教会 [CUL_RELIGIOUS] [データ]
  正例1    由緒ある神社で、静かな境内を歩きながらお参りしました。
  正例2    ステンドグラスが美しい教会で、礼拝堂の雰囲気に感動しました。
  境界例    「〇〇神社前」というバス停の名前が出てくるだけで、神社そのものへ
           の訪問は書かれていませんでした。→ 付与しない(2-2 EXCEPT、
           地名の一部)。

2-3. 城跡・城郭・宮殿 [CUL_CASTLE] [定義のみ・未検証]
  正例1    天守閣からの眺めが素晴らしく、当時の建築技術に感心しました。
  正例2    復元された城門をくぐり、城郭内を見学しました。
  境界例    城があった場所、と書かれていましたが、現在は石垣しか残っておらず
           建物は失われていました。→ 2-1(史跡)を検討(2-3 EXCEPT)。

2-4. 集落・街 [CUL_TOWNSCAPE] [データ]
  正例1    昔ながらの街並みが続く通りを歩くだけで楽しかったです。商店が軒を
           連ねていました。
  正例2    歴史的な建物が並ぶ地区全体を散策しました。
  境界例    通り沿いの一軒のお店について書かれているだけで、街並み全体への言
           及はありませんでした。→ 付与しない(2-4 EXCEPT、単一
           建築物)。

2-5. 郷土景観 [CUL_LOCALSCAPE] [定義のみ・未検証]
  正例1    棚田の風景が広がり、その土地の農業の営みを感じられました。
  正例2    漁港の雰囲気が残る町並みで、水揚げの様子も見ることができました。
  境界例    昔は農業が盛んだった、という歴史の説明だけで、現在の景観がその生
           業と結びついているわけではありませんでした。→ 2-1を検討(2-5
           EXCEPT)。

2-6. 庭園・公園 [CUL_GARDEN] [データ]
  正例1    手入れの行き届いた庭園を散策し、四季の移ろいを感じました。
  正例2    広々とした公園で、芝生の上でのんびり過ごせました。
  境界例    「〇〇公園に行った」とだけ書かれていて、園内の様子への言及が一切
           ありませんでした。→ 付与しない(2-6 EXCEPT)。

2-7. 建造物 [CUL_BUILDING] [データ]
  正例1    レトロな洋館の意匠が美しく、建物を見るだけでも価値がありました。
  正例2    橋のデザインが印象的で、ライトアップされた姿も綺麗でした。
  境界例    建物の中で開催されていた展示の内容について書かれているだけで、建
           物自体の構造や意匠への言及はありませんでした。→ 2-10を検討
           (2-7 EXCEPT)。

2-8. 年中行事 [CUL_EVENT] [定義のみ・未検証]
  正例1    地域の祭礼の時期に訪れることができ、賑やかな雰囲気を味わえました。
  正例2    毎年恒例の花火大会に合わせて行きました。
  境界例    「夏には祭りがあるらしい」と伝聞で触れているだけで、実際にその時
           期に訪れたわけではありませんでした。→ 付与しない(2-8 EXCEPT)。

2-9. 動植物園・水族館 [CUL_ZOO] [データ]
  正例1    飼育員による解説を聞きながら、普段見られない動物をじっくり観察で
           きました。
  正例2    大水槽を泳ぐ魚の群れが幻想的でした。
  境界例    野生の動物を自然の中で見かけた、という記述でした。施設での飼育展
           示ではありません。→ 1-8を検討(2-9 EXCEPT)。

2-10. 博物館・美術館 [CUL_MUSEUM] [データ]
  正例1    企画展の展示内容が充実していて、じっくり時間をかけて見て回りまし
           た。
  正例2    所蔵されている絵画のコレクションが見応えがありました。
  境界例    入場料が少し高いと感じた、という感想だけで、展示の内容そのものへ
           の言及はありませんでした。→ 4-6を適用し、その他または付与し
           ない。

2-11. テーマ公園・テーマ施設 [CUL_THEMEPARK] [定義のみ・未検証]
  正例1    特定のテーマに沿ったアトラクションが充実していて、一日中楽しめま
           した。
  正例2    参加型の体験コーナーが多く、子供も飽きずに過ごせました。
  境界例    広い敷地の緑地の中に遊具がいくつかある、という程度の記述で、テー
           マ性への言及はありませんでした。→ 2-6を検討(2-11 EXCEPT)。

2-12. 温泉 [CUL_ONSEN] [定義のみ・未検証]
  正例1    露天風呂から見える景色が最高で、湯質も良かったです。
  正例2    泉質の効能が有名な温泉地で、湯めぐりを楽しみました。
  境界例    宿泊した旅館に温泉があった、という付帯設備としての記述にとどまっ
           ていました。→ 付与しない(2-12 EXCEPT)。

2-13. 食 [CUL_FOOD] [データ]
  正例1    その土地ならではの郷土料理を味わうことができ、満足しました。
  正例2    老舗として知られるお店の味を楽しみに訪れました。
  境界例    「この辺りで何か食べた」とだけ書かれていて、具体的な料理や店への
           言及がありませんでした。→ 4-6を適用し、その他または付与しな
           い。

2-14. 芸能・スポーツ [CUL_PERFORM] [定義のみ・未検証]
  正例1    地域に伝わる伝統芸能の公演を鑑賞することができました。
  正例2    民謡大会の雰囲気を楽しみました。
  境界例    プールやテニスコートがある、という一般的なスポーツ施設の列挙にと
           どまっていました。→ 付与しない(2-14 EXCEPT)。


────────────────────────────────────────
7-B. 併記の境界例 [v1.4 で追加]
────────────────────────────────────────

第7章の境界例は、24タイプすべてが「付与しない」型であり、複数タイプを
併記すべき境界例を欠いていた。ここに、現行の規則文(3-3、3-5、3-7、
1-3、1-6、1-9、3-10)が併記を許している範囲で、併記の例を6
件示す。すべて架空の記述であり、実在の施設の説明文を写したものではない(
0-5)。

出典区分は [データ由来の型・架空例] とする。評価用施設の人手ラベルに
現れた併記のパターンを抽象化して作成したため、パターンの水準では開発デー
タと重なる。評価には、これらの型に該当しない別の施設を用いること(6-7)。

7B-1. 集落・街 + 食 [データ由来の型・架空例]
  入力例    石畳の通りに、地元の麺料理や煮込み料理を出す食堂が数十軒が軒を
          連ね、通りの入口には石造りのアーチが立つ商店街。
  付与      CUL_TOWNSCAPE + CUL_FOOD
  根拠      2-4(常設の商店街は集落・街)、3-7(飲食店が面的に集積
          し、街並みが独立して記述されているため併記)、2-13(料理
          が訪問理由)。
  区別点    3-7 が要求する「街並みの独立した記述」(通り・入口の構造
          物など)があるか。単一の店舗だけの記述なら 2-4 の境界例
          のとおり非付与。※2-13 と 3-7 の矛盾は未解決(7B
          末尾)。

7B-2. 建造物 + 集落・街 [データ由来の型・架空例]
  入力例    丘の上の通り沿いに、明治期に建てられた洋風の住宅が数棟並ぶ。
          それぞれ設計者や意匠が異なり、室内も見学できる。通り全体が落
          ち着いた住宅街の雰囲気を残している。
  付与      CUL_BUILDING + CUL_TOWNSCAPE(多
          ラベル運用のみ)
  根拠      3-5(個別の建築物の記述と区域全体の景観的まとまりの記述が
          並立するため併記)、2-7。
  区別点    個別の建築物の記述だけなら CUL_BUILDING のみ、
          区域全体のまとまりの記述だけなら CUL_TOWNSCAPE
          のみ。※「〜群」とだけ書かれた場合の扱いは v1.3 に規則
          がなく未定(7B 末尾)。

7B-3. 庭園・公園 + 植物 [データ由来の型・架空例]
  入力例    整備された広い公園で、早春には数百本の梅が丘一面に咲く。見頃
          には梅林を巡る道が整えられ、見物客でにぎわう。
  付与      CUL_GARDEN + NAT_PLANT
  根拠      2-6(整備された緑地)、1-9 の THEN と 3-10
          (植物の鑑賞が訪問理由として記述されているため併記)。
  区別点    1-9 の境界例のように「植物が植えられている」程度の記述な
          ら CUL_GARDEN のみ。見頃・鑑賞のための道など、植
          物自体が見どころとして記述されているかが分かれ目。

7B-4. 庭園・公園 + 湖沼 [データ由来の型・架空例]
  入力例    公園の中央に大きな池があり、池を一周する遊歩道と貸しボートが
          ある。水面に映る木々を眺めながら散策できる。
  付与      CUL_GARDEN + NAT_LAKE
  根拠      2-6、1-3(水面の景観・水辺の周遊・水上活動が訪問理由と
          して提示されているため併記)。
  区別点    1-3 の境界例のように、池が公園の設備の一つとして触れられ
          るだけなら CUL_GARDEN のみ。※複数の設備の列挙の
          中に「池」がある型の扱いは未決(7B 末尾)。

7B-5. 庭園・公園 + 海岸・岬 [データ由来の型・架空例]
  入力例    整備された芝生の園地の先に砂浜が広がり、波打ち際を歩ける。夕
          方には海岸線に沿って散策する人が多い。
  付与      CUL_GARDEN + NAT_COAST
  根拠      2-6、1-6(砂浜・海岸線の散策という自然の海岸風景が記述
          されているため併記。JTB定義に沿う)。
  区別点    1-6 の境界例のように「海に面している」とだけ書かれ、砂浜
          ・岩礁などの海岸地形への言及がなければ CUL_GARDEN
          のみ。※「臨海」とだけ書かれた場合に海岸・岬を付ける扱いは
          JTB 定義の拡張になり、未実装(7B 末尾)。

7B-6. 庭園・公園 + 建造物 [データ由来の型・架空例]
  入力例    回遊式の庭園の中に、江戸時代の茶室と土蔵が保存されており、内
          部の見学ができる。
  付与      CUL_GARDEN + CUL_BUILDING(多ラベル
          運用)
  根拠      3-3(整備された緑地空間の内部に歴史的建築物が所在し、多ラ
          ベル運用では併記)、2-7。
  区別点    3-3 の EXCEPT のとおり、建築物への言及が沿革の説
          明にとどまるなら CUL_GARDEN のみ。内部の見学など、
          建築物の観覧が記述されているかが分かれ目。

7B-未解決. 併記例では解消できない問題(規則本文の改訂が必要・未実施)
  (a) 2-13 は「面的に集積した区域は付与しない(3-7に従う)」、
  3-7 は「CUL_FOOD を付与」と書き、互いに矛盾している。3-7
  は食を先に付け、街並みが独立して記述された場合に限り集落・街を併記す
  る順序だが、JTB は常設の商店街を集落・街としている。
  (b) 設備の列挙の中に池や植物が挙げられる型(「池、〜、〜を備えた
  公園」)は、0-4 の「主対象」要件と 1-3・1-9 の EXCEPT
  により、非付与側に判定される。併記とするか非付与とするかは研究者の判
  断を要する。
  (c) 「臨海」「海に面する」とだけ書かれた公園に海岸・岬を付けるか
  は、1-6 の境界例が非付与を示しており、付けるには JTB 定義の
  拡張規則が必要。
  (d) 「〜群」「〜が立ち並ぶ」を建築物の集積とみなして集落・街へ振
  り分ける規則(v2 の 0-6、3-5)は v1.3 系に存在しない。
